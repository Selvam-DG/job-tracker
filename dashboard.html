Google Sheet connection

Use the sheet-bound Apps Script v3, deployed as a web app. This extension stores connection settings locally, not job records.

Legacy import is optional and does not clear old Chrome records. Back up your sheet before importing. Edits made directly to the Applications sheet can be read on Reload; edits to its Status column are not automatically added to Status History.
